# Что сказать преподавателю

1. XAML описывает интерфейс, а MainPage.xaml.cs содержит обработчики событий.
2. partial объединяет написанный код страницы с кодом, созданным из XAML.
3. InitializeComponent загружает разметку и связывает именованные элементы с C#.
4. У каждого элемента уникальное x:Name с подчёркиваниями по краям.
5. ScrollView позволяет прокручивать анкету на маленьком экране.
6. StackLayout размещает элементы последовательно; Padding, Margin и Spacing задают отступы.
7. Grid размещает флажки, переключатель и ползунок с числом по строкам и столбцам.
8. Keyboard.Text и Keyboard.Email выбирают подходящую экранную клавиатуру; сами данные они не проверяют.
9. RadioButton с одинаковым GroupName допускают один выбор. CheckBox независимы.
10. Binding получает Value ползунка через x:Reference. OneWay обновляет Label при движении Slider.
11. TextChanged скрывает подсказку, когда заполнены имя и email; кнопка отдельно проверяет оба поля и формат email.
12. Обработчик результата читает значения контролов, собирает строку и показывает область результата.
13. Очистка сбрасывает каждый контрол, дату, ползунок, сообщения и прокрутку.
14. Изображение developer.svg входит в Resources/Images; MAUI создаёт из SVG ресурс developer.png.
15. App создаёт окно с AppShell, а Shell открывает MainPage. MVVM и сторонних библиотек нет.
